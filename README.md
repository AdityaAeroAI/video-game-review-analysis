# Video Game Review Data Analysis

## Project Overview
This project focuses on statistical analysis and visualization of video game review data to study gameplay behavior patterns and the relationship between hours played and review scores.

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

---

## Objectives
- Analyze review score distribution
- Study gameplay behavior patterns
- Evaluate correlation between hours played and review scores
- Detect outliers and variability in review data

---

## Data Preprocessing
Performed preprocessing tasks including:

- Missing value handling
- Duplicate record removal
- Data formatting
- Statistical cleaning

---

## Statistical Analysis
### Pearson Correlation Analysis
Analyzed the relationship between:

- Hours Played
- Review Score

### Distribution Analysis
Studied:

- Central Tendency
- Variability
- Outliers
- Distribution Spread

---

## Visualizations
Generated visualizations including:

- Scatter Plots
- Heatmaps
- Grouped Box Plots
- Correlation Charts

---

## Key Insights
- Identified gameplay behavior patterns
- Evaluated relationship between playtime and review scores
- Detected score variability and outliers
- Interpreted statistical significance from real-world datasets
